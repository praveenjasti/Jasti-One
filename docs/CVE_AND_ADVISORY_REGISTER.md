## Required register workflow
1. Re-scan the exact release lock and installed environment on every pull request and weekly.
2. Confirm affected version, transitive path, component use and reachable code path.
3. Corroborate relevant findings using NVD, GitHub Security Advisories, OSV and official vendor notices.
4. Record fixed versions, mitigations and owner-approved, time-bound exceptions.

The 21 November 2026 targeted recheck queried the NVD 2.0 API, GHSA, OSV and lxml vendor release/issue pages for the known lxml findings. CAR-002 is fixed before 6.1.0, and NVD/GHSA/OSV agree on that threshold. The vendor also marked LP#2165901 fixed in lxml 6.1.3; this was not represented by a CVE/GHSA/OSV identifier in the sources checked. The lock resolves 6.1.3. This targeted review is not an all-package manual advisory review.

The final scan is against the Python 3.13 locked development environment, not a production distribution artifact. The generated SBOM includes optional Gmail and development tools. Current `pip-audit` runs found no indexed issues in the tested graphs; that result does not prove security or complete NVD/GHSA/vendor coverage. Bandit is a static analyzer, not a vulnerability proof.
